\section{Introduction}\label{sec:intro}

Double reading pays off when the second reader errs on different cases from the first reader~\cite{taylor2008double,geijer2018double,kurvers2016pooling}. Medical multi-agent systems coordinate role-prompted instances of one model through voting or multiagent debate~\cite{kim2024mdagents,tang2024medagents,du2024debate,kim2026scaling}.

Agents of one VLM share the vision encoder, the language model and its language prior. A role prompt changes instructions; it changes neither what the vision encoder sees nor the answer the model falls back on when the image does not decide the question. Majority vote corrects an agent when others err on different items~\cite{clemen1985limits}; when they fail together, it returns their shared error. The gain available to a MAS of one VLM is set by error correlation rather than agent count.

We measure error correlation $\phi$ and the effective number of independent agents $N_{\mathrm{eff}}$~\cite{kish1965survey}, and relate them to majority accuracy with a beta-binomial model (\cref{fig:teaser}). We vary the image through blanking, reduced resolution, occlusion and pairing, and vary shared components through roles, contrast adjustment, in-context examples, reports and models. Query-agnostic reports separate perception from reasoning~\cite{qiao2024prism}. We compare Independent and Decentralized MAS with single-agent and self-consistency baselines across proprietary and open-weight VLMs (\cref{sec:setup}).

Our contributions are:
\begin{itemize}
\item \textbf{Measuring dependence.} We measure how many independent agents a MAS of one VLM provides and show that mean agent accuracy and error correlation predict majority accuracy. We decompose multi-agent gains into gains from better agents and gains from the vote.
\item \textbf{Tracing shared errors.} We use blank-image probes to show that shared wrong answers follow the answer the model gives without visual evidence.
\item \textbf{Separating shared components.} We use query-agnostic reports to show that the perception module sets accuracy and a shared report sets error correlation. Matched contrasts show that changing the model decorrelates agents more than changing their role or input.
\item \textbf{Tracking conformity.} We compare initial with final answers to show that debate changes correct minority answers to wrong answers.
\end{itemize}
