\section{Conclusions}

Reading panels built from the same VLM shared errors that limited the benefit of majority voting. Panel accuracy depended on both individual reader accuracy and error correlation. Question-text priors contributed to shared errors, and a shared findings report increased error correlation. Different models reduced error correlation more than changes in roles, image rendering, or reference cases within a model. Discussion increased agreement and overturned correct minority answers, including answers dependent on image evidence. A reading panel of one model's readers is closer to one read than to nine, and a second AI read adds independent information when a different model performs the seeing.
