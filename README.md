# Nine Agents from One VLM Are Worth Fewer Than Two

Paper sources for a controlled evaluation of multi-agent systems built from one vision-language model
on radiology images. Code, data and figure scripts: https://github.com/hq0709/consultation-arithmetic

| Folder | Version | Main document |
|---|---|---|
| `cvpr/` | CVPR 2026 submission (review mode) with supplementary material | `cvpr/main.tex` |
| `radiology/` | Meta-Radiology manuscript | `radiology/main.tex`, `radiology/supplement.tex` |

## Compiling

- Overleaf: set *Menu → Settings → Main document* to `cvpr/main.tex` (or a radiology file). The
  root `latexmkrc` lets BibTeX find each paper's `.bib` and `.bst` files in its own folder.
- Locally: `cd cvpr && tectonic -X compile main.tex` (XeTeX). pdfLaTeX also works; the sources are ASCII.

Figures are generated by the code repository (`experiments/cvpr_fig/`, `experiments/radiology_fig/`)
and committed here as PDFs.
